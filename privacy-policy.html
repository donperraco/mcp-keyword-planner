Política de privacidad — mcp keyword planner

Vigente desde: 22 de octubre de 2026

1. Qué es esta aplicación

mcp keyword planner es una herramienta de software de uso estrictamente personal que se ejecuta en el ordenador de su único usuario y actúa como conector (servidor MCP, Model Context Protocol) entre Google Ads (Keyword Planner / API de Google Ads) y un agente de IA para tareas de investigación de palabras clave. No es un servicio web: no ofrece registro, ni cuentas, ni acceso a terceros.

2. Qué datos accede

Previa autorización explícita de su propietario mediante OAuth 2.0 (alcance https://www.googleapis.com/auth/adwords), la aplicación consulta a la API de Google Ads únicamente sobre las cuentas de Google Ads del propio propietario: ideas de palabras clave, volúmenes de búsqueda, niveles de competencia, rangos de pujas estimadas y pronósticos de rendimiento.

3. Dónde se guardan los datos

  • Los tokens de acceso (incluido el refresh token) se almacenan exclusivamente en un archivo local con permisos restringidos (0600) en el equipo del usuario.
  • Las respuestas de la API se muestran al usuario y pueden aparecer en sus conversaciones con su agente de IA local; la aplicación no las persiste en ningún servidor.
  • La aplicación no opera bases de datos, analíticas ni servidores externos.

4. Qué no hacemos

  • No recopilamos datos personales de terceros ni de visitantes de esta web.
  • No vendemos, alquilamos ni compartimos datos con terceros.
  • No utilizamos los datos para publicitar ni para entrenar modelos de ningún proveedor.
  • No accedemos a cuentas de Google Ads distintas de las del propietario autorizado.

5. Derechos y control

Como la app solo procesa datos del propio titular, este controla íntegramente su ciclo de vida:

  • Rtiro del acceso: revocable en cualquier momento desde myaccount.google.com/permissions (sección "Apps con acceso a tu cuenta"). Al eliminar la app, los tokens locales pueden borrarse del archivo de configuración.
  • Eliminación de datos locales: borrar el fichero de credenciales y el binario elimina todo rastro; no hay copias en ningún otro sitio.

6. Seguridad

Las credenciales OAuth se guardan con permisos de solo lectura para el usuario del sistema y nunca se muestran ni transmiten a terceros distintos de Google. Las comunicaciones con la API de Google Ads viajan cifradas (HTTPS).

7. Cambios

Si esta política cambia en el futuro, se actualizará la fecha de vigencia de esta página.
